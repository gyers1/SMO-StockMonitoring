# SMO third-party components

SMO uses Python, PySide6/Qt (LGPLv3), Shiboken6, httpx2, Pydantic and the dependencies pinned in requirements-lock.txt. Original package license texts are included under assets/licenses. Qt libraries are dynamically linked and may be replaced with compatible modified versions; SMO's application source and rebuild instructions are provided with this project. Do not prohibit reverse engineering for debugging modifications to LGPL components.

Qt source: https://download.qt.io/archive/qt/6.12/
PySide/Shiboken source: https://download.qt.io/official_releases/QtForPython/
Python source: https://www.python.org/downloads/source/
Pretendard is distributed under SIL Open Font License 1.1; see assets/fonts/OFL.txt.
The Korean instrument catalog is derived from Korea Investment public exchange masters; it contains instrument metadata, not redistributed broker quotes.

Each user supplies their own brokerage API credentials and is subject to that broker's market-data entitlements. No keys or account information are included.
